## 技能概述

### 什么是 aliyun-domain？

**aliyun-domain** 是一个通过阿里云 OpenAPI 管理域名资产的技能，支持域名查询、续费、转移、注册、信息修改等全生命周期管理操作。

| 传统方式 | 使用技能后 |

| 手动登录阿里云控制台 | 对话式操作，无需登录 |
| 逐个检查域名可用性 | 批量自动检查，秒级出结果 |
| 手动记录优惠政策 | 内置完整优惠知识库 |
| 凭经验判断热点 | AI 驱动热点分析 |
| 手动计算成本 | 自动成本估算 + 优惠推荐 |

### 批量检查实战

**示例代码**：

```python
from aliyun_domain import AliyunDomainClient

client = AliyunDomainClient()

# 投资人自定义组合
keywords = ['ai', 'bot', 'agent', 'claw']
suffixes = ['cn', 'com', 'io', 'ai']
patterns = ['{k}{n}.{s}', 'try{k}.{s}', '{k}88.{s}', '{k}168.{s}']

available = []
for k in keywords:
    for s in suffixes:
        for p in patterns:
            domain = p.replace('{k}', k).replace('{s}', s).replace('{n}', '88')
            result = client.check_domain(domain)
            if result.get('available', False):
                available.append(domain)

print(f'可注册：{len(available)} 个')
```
