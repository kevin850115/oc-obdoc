当您需要了解域名的注册商信息、域名状态、到期日期等信息时，可以使用WHOIS进行查询。

查询入口：域名信息查询（WHOIS）。

Registrant E-mail

应ICANN临时政策与GDPR合规要求，阿里云的WHOIS信息公开查询结果中已不再显示域名注册者的个人信息。

如注册商为阿里云的域名，可尝试点击页面上的“如要进行联系，请在线填写信息”联系域名所有者。

如果涉及域名滥用（如钓鱼、诈骗），请联系英文信息中显示的 Registrar Abuse Contact Email（注册商滥用举报邮箱）。

Sponsoring Registrar

当前为该域名提供注册服务的服务商，您需要登录这家服务商的控制台才能管理域名。

Registration Date (UTC)

Expiration Date (UTC)

域名到期日期。为避免服务中断或域名被他人抢注，请务必在此日期前完成续费。

建议您在域名控制台开启自动续费功能。

Domain Status

一个域名可以同时拥有多个状态，请参见域名状态码说明。

Name Server

域名当前的解析服务器，负责将域名指向网站服务器的“导航系统”。 如果网站无法访问，请检查此处的DNS服务器地址是否配置正确。如需修改，请参见修改DNS服务器。

您可以通过英文信息查看原始WHOIS信息，字段说明请参见ICANN Lookup FAQ。

请根据查询到的域名状态码，在此查找其含义和建议操作。

client 开头：表示该状态由域名注册商设置。注册商（Registrar）是您直接购买和管理域名的服务商，例如阿里云。

server 开头：表示该状态由域名注册局设置。注册局（Registry）是顶级域名的最高管理机构，例如CNNIC（China Internet Network Information Center，中国互联网信息中心）

状态码 (EPP Status Code)

正常状态。域名可正常使用，且未设置任何安全锁。

ok 是域名的基础健康状态。当域名附加了任何其他状态时，ok 状态通常会被隐藏。这不代表域名无法使用。

建议操作：为防止域名被盗，建议您前往控制台为域名开启禁止转移锁和禁止更新锁。

新注册保护期。域名新注册5天内会显示此状态。

无需操作。不影响域名的正常使用，5天后自动解除该状态。

注册商设置暂停解析，域名将无法访问。

请检查是否因未完成实名认证、域名涉及违规内容或存在争议导致。您需联系注册商解除该状态。更多信息，请参见解除域名锁定状态Clienthold、Serverhold。

注册局设置暂停解析，域名将无法访问。

“.cn”域名注册成功后，如果未通过实名审核一般会出现该状态，您需在域名有效期内完成实名审核，审核通过后会解除该状态。更多信息，请参见解除域名锁定状态Clienthold、Serverhold。

clientRenewProhibited

注册商或注册局设置禁止续费。通常因为域名处于法律仲裁或争议中。

处于该状态的域名无法进行域名续费，请联系注册商确认原因。

serverRenewProhibited

clientTransferProhibited

注册商或注册局设置禁止转移，域名将不能转移注册商。

正常安全状态。如需将域名转移至其他注册商，请先登录域名控制台关闭禁止转移锁。

serverTransferProhibited

部分新注册的域名或域名转移注册商60天内会被注册局设置禁止转移，60天后会自动解除该状态。

部分域名涉及仲裁或诉讼案被注册局设置禁止转移，仲裁或诉讼案结束会解除该状态。

clientUpdateProhibited

注册商或注册局设置禁止更新，域名注册人、管理联系人、技术联系人、付费联系人、DNS服务器等信息不能被修改，但可以设置或修改解析记录。

正常安全状态。如需修改域名信息，请先登录域名控制台关闭禁止更新锁。

serverUpdateProhibited

如需修改域名信息，请联系注册商确认原因。

clientDeleteProhibited

注册商或注册局设置禁止删除，域名将无法被删除。

如确实需删除域名，请联系注册商确认原因。

serverDeleteProhibited

未激活。通常因为注册时未填写有效的DNS服务器。

需要操作。请登录域名控制台，为域名设置正确的DNS服务器地址，否则域名无法解析。

pendingVerification

注册信息审核期。新注册域名后，未完成所有者实名认证。

需在域名注册成功后5天内提交实名资料进行审核，逾期域名将被 serverHold 并暂停解析。具体操作，请参见通用域名实名认证。

pendingTransfer

注册局设置转移过程中，域名正处于转移注册商的过程中。

观察状态，等待转移完成即可。如果您未主动操作转移，请立即联系原注册商核实是否存在被盗风险。

autoRenewPeriod

续费宽限期。域名已过期，进入了为期约30天的续费宽限期。

建议尽快操作域名续费。如果未在续费宽限期内成功续费，将进入高价赎回期，需要用高于正常续费价格的费用来

redemptionPeriod

注册局设置赎回期。域名已过期一段时间，处于高价赎回期。

建议尽快联系注册商高价赎回域名，但这是保留域名的最后阶段。

pendingDelete

国际域名 (.com/.net/.org 等)：表示域名已过赎回期，正等待被删除。此状态下无法恢复。

删除后将对外重新开放注册，可尝试重新注册。

国内域名 (.cn/.com.cn 等)：表示域名正处于高价赎回期。

建议尽快联系注册商高价赎回域名，但这是保留域名的最后阶段。

在了解域名信息后，建议执行以下操作以确保域名的安全与正常运行：

管理域名安全：检查域名是否处于 clientDeleteProhibited 和 clientTransferProhibited 状态。如果不是，建议在域名控制台开启禁止转移锁和禁止更新锁，以防止域名被盗。

管理域名续费：检查到期日期，确保为重要域名开启自动续费功能，避免因忘记续费导致业务中断和域名丢失。

配置域名解析：如果域名尚未解析，请前往控制台配置域名解析，将域名指向网站服务器或邮箱服务器。

Q: 为什么我查不到我的域名信息？

A: 阿里云WHOIS工具仅支持查询阿里云提供注册服务的域名后缀。对于不在域名价格总览列表等后缀，可使用ICANN官方查询入口或其他WHOIS工具进行查询。

Q: 为什么 WHOIS 查询结果显示的域名到期日，和我在其他地方查到的不一样？

A: 这通常由时区差异或不同平台的数据缓存延迟导致。请以您域名所在注册商官方控制台显示的到期日期为最准确依据。

Q: 我的域名状态是 clientTransferProhibited，这是不是不正常？

A: 这是正常的安全状态。它像一把锁，能有效防止您的域名被恶意转移。我们强烈建议您在日常保持此状态开启。只有当您需要将域名转移到其他服务商时，才需要手动解锁。
